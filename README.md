# 多标签页共享任务板

纯 HTML、CSS、DOM、Canvas 与 JavaScript 实现，不使用任何框架。数据保存在同源共享的 IndexedDB 中。

## 运行

建议使用本地静态服务器打开，以获得完整的浏览器能力：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`，复制到 4 个或更多标签页。

## 功能

- 创建、编辑、删除任务。
- 认领、释放、完成任务。
- 待认领、已认领、已完成三种状态实时展示。
- 按状态、标签页、关键词过滤，并支持创建时间、优先级、标题排序。
- 每个标签页的认领任务独立分组展示。
- Canvas 实时展示三列任务状态及各标签页颜色。
- “模拟离线”按钮会暂停当前标签页的广播和共享写入；离线认领请求持久化在 IndexedDB 中。

## 并发设计

- 所有任务变更都先获取全局 Web Lock `shared-task-board:write`，因此 4 个标签页同时点击同一任务时，只有一个标签页能将状态从 `unclaimed` 改为 `claimed`。
- 每个标签页持有一个独占会话锁。标签页关闭或崩溃后浏览器自动释放锁；其他标签页的定期协调器会删除失效会话，并把其任务改回 `unclaimed`。
- 刷新时复用 `sessionStorage` 中的身份并重新申请同一会话锁，短宽限内不会误释放任务。
- 每次变更先提交 IndexedDB，再追加事件并通过 BroadcastChannel 通知。消息到达后接收方重新读取数据库，而不是直接信任消息内容，所以消息乱序不会覆盖新状态或丢任务。
- 离线认领不提前改动共享任务，只写入本地队列。恢复连接后按队列顺序在全局锁内重放，成功则认领，失败则明确标记冲突。
- 标签页加入、恢复、心跳和自动回收都会触发快照刷新，动态增减标签页后状态一致。

## 手动验收

1. 打开 4 个标签页，创建一个任务，4 页同时点击“认领”：只有一页成功，其他页显示冲突。
2. 关闭成功认领任务的标签页：等待约 4 秒，其他标签页中任务回到“待认领”；刷新当前标签页不会触发释放。
3. 在一个标签页点击“模拟离线”，对任务点“离线认领”，再恢复连接：若任务未被他人认领则成功，否则队列标记冲突。
4. 连续创建、认领、释放、完成任务：所有标签页状态和 Canvas 同步。
5. 刷新任一标签页：任务状态不变；刷新当前认领者后，任务仍归属该标签页。
